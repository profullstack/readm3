Make yourself at home.

    
The readm3 terminal reader, in your browser. Open a folder or a few Markdown files to get started.

    
↑ / ↓ or j / k
Move through files or scroll the reader
← / →
Collapse or expand a folder
Enter
Open the focused file
/
Filter files
Tab
Move between controls and panes
e / i · Escape
Edit source · return to reading
Ctrl / ⌘ S
Download the current Markdown file
g / G · Space / b
Top / bottom · page down / up
s · ?
Reveal spoilers · open help

    
Files and edits are saved in this browser for offline use. Download a copy to keep it outside the browser; clearing site data removes the workspace. Opening a file does not change the original on disk.

    
Install from your browser’s install menu, or on iPhone and iPad use Share → Add to Home Screen. After your first visit, the reader works offline. URLs need an internet connection and a host that allows browser access.

    

  
  
    
Open a Markdown URL

    
Paste a raw Markdown URL or a GitHub file link. The file is fetched directly from its host and added to your workspace.
